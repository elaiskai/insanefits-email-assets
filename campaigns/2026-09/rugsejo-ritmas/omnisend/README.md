# Omnisend importas

## Failai

newsletter-omnisend.html yra laiško turinys be DOCTYPE, head ir body žymų.
styles.css yra laiško CSS, įskaitant telefono išdėstymą.
Pagrindinis newsletter.html yra pilna naršyklės peržiūros versija vienu aplanku aukščiau.

## Importas

Omnisend atidaryk Store Settings → Saved Templates → Import Template → Paste HTML Code.
HTML laukelyje naudok newsletter-omnisend.html turinį.
Styles laukelyje įklijuok styles.css turinį be style žymų.
Jei renkiesi failo importą, įkelk newsletter-omnisend.html ir po importo patikrink CSS redaktoriuje.

Visos nuotraukos jau turi viešus HTTPS adresus. Vietinio assets aplanko atskirai įkelti nereikia.
Nuotraukų adresai užfiksuoti konkrečioje GitHub versijoje, todėl vėlesni repo pakeitimai jų nepakeis.
Prenumeratos atsisakymo nuoroda naudoja Omnisend žymą [[unsubscribe_link]]. Patikrink jos veikimą pačioje Omnisend kampanijoje.
Prieš siuntimą patikrink desktop ir mobile peržiūras bei išsiųsk testą sau. Importas Omnisend paskyroje dar neatliktas.

Ši versija turi tris Creatine Chews skonius ir Pure Creatine be skonio. Fusion Fruit šiame makete nepridėtas.

Oficiali importo instrukcija: https://support.omnisend.com/en/articles/2964086-import-custom-html-email-templates
CSS instrukcija: https://support.omnisend.com/en/articles/1061866-add-configure-custom-html-item
